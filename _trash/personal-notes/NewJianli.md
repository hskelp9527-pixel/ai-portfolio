1、TimeReminder
项目描述（新）

针对传统待办工具需要用户频繁查看、容易错过执行时机的问题，设计并实现了一款 Windows 桌面任务提醒工具 TimeReminder。

产品以“设好就不管”为核心理念，用户只需输入截止时间与预计耗时，系统即可自动推导“应开始时间”，并在关键节点通过系统级通知进行强提醒，减少用户的认知负担。

核心设计与实现（新）

基于「截止时间 − 预计耗时」的时间推导逻辑，自动计算提醒时机

采用 Windows Toast 通知，实现必须确认的强提醒机制

托盘常驻与开机自启设计，保证提醒不被遗漏

本地 SQLite 存储，免配置、免服务端，支持数据导入导出

打包为单文件 exe，双击即用，降低使用与分发成本

项目价值（新）

将任务管理从“主动查看”转为“被动提醒”，显著降低遗忘风险

特别适合对时间敏感、但不愿维护复杂待办系统的用户

体现了对用户认知成本与产品简洁性的取舍思考

2、项目名称（建议）

基于 Dify 的个人知识库问答系统（RAG）

（如果你想更偏技术，可用英文副标题）

项目描述（新）

为解决个人项目资料分散、难以快速检索与复述的问题，基于 Dify 平台构建了一套 个人知识库问答系统。

系统通过知识检索增强生成（RAG）机制，将个人项目文档、产品总结等资料转化为可对话的智能知识库，实现对个人经历与项目的自然语言问答。

核心实现（新）

构建混合检索知识库（向量检索 + 关键词检索），提升召回准确率

基于 Chatflow 设计「用户输入 → 知识检索 → LLM → 回复」的问答流程

通过 Prompt 约束，强制模型仅基于知识库内容回答，避免幻觉

对项目类问题采用结构化输出（背景 → 方案 → 价值）

项目价值（新）

将静态简历与项目文档升级为可交互的 AI 简历

支持快速回答“做过什么 / 项目如何设计 / 有何价值”等高频问题

为后续扩展多知识库或 Agent 应用提供基础架构
